# Sir0xGhanem's blog

Jekyll + [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy), deployed to GitHub Pages with GitHub Actions.

## Writing a post

1. Copy `_templates/episode.md` to `_posts/YYYY-MM-DD-eigenlayer-deep-dive-NNN-short-title.md`.
2. Keep `categories: [EigenLayer Deep Dive]` exactly the same in every episode.
3. The post date must not be in the future, or Jekyll skips the post.
4. Push to `main` and the site builds by itself.

Work in progress goes in `_drafts/`.
